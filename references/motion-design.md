# 动效与分镜：闸门全绿之后，为什么还是难看

这份文件解决一个具体的失败：**一支片子通过了全部自检，节奏指标也在"灵动"档，但人一看就说"动效和分镜不好"。**

它不重复 [choreography.md](choreography.md) 的编排规则，也不重复 [rhythm-handoff.md](rhythm-handoff.md) 的交接数字。它只回答一件事：那些检查**看不见**的东西是什么，以及怎么在花掉渲染时间之前把它量出来。

> 立论来自一次真实交付：30 秒、2K60、白底一镜到底。`check` 0 问题，`beat_audit` 全过，`verify` 六项全绿，节奏四项全在"灵动"档。用户的评价是"动效与分镜设计并不好"。用本文的工具回测那支成片，它给出的判据是 **no_weight_variety**——三条直觉里只有一条成立。

---

## §0 为什么现有闸门看不见

| 工具 | 它证明的事 | 它证明不了的事 |
| --- | --- | --- |
| `check` | 没有出框文字、没有 NaN、对比度够 | 这一帧好不好看 |
| `beat_audit` | 交接有重叠、没有空档、窗口不过长 | 交接的**两端**值得看 |
| `verify` | 有画面、在动、有声 | 动的是不是**值得动的东西** |
| `taste_check --rhythm` | 画面一直有变化 | 变化有没有**对比** |
| `taste_check --stills` | 单帧的留白、对称、墨团 | 拍与拍之间是否**互不相同** |

共同盲区：**它们都在测"有/没有"，没有测"对比"。** 而"难看"几乎总是对比缺失，不是存在性缺失。

## §1 四个判据（`scripts/design_audit.py`）

```bash
python scripts/design_audit.py draft.mp4 --project work/mine/project.json --ascii
```

| 判据 | 测什么 | 阈值 | 失败意味着 |
| --- | --- | --- | --- |
| `no_weight_variety` | 每一拍的墨量与暗量 | 至少一拍 ≥12% 墨或 ≥3% 暗 | 全片一个重量：从头到尾都是"白底 + 细线"，眼睛没有轻重对比 |
| `flat_rhythm` | P90/均值 | <1.25 失败；快片 <1.70 警告 | 节奏是一条平线：没有重音，也就没有"快"的参照 |
| `no_pause` | 可读停顿（按**变化像素比例**计，≥0.3s） | 20s 以上至少 2 个 | 没有任何东西被停住读；每一帧都是过路 |
| `layout_repeat` | 拍与拍之间的墨布局相似度 | 中位数 ≥0.88 且墨量跨度 <2.5× | 同一构图穿了 N 次 |

**为什么停顿要按像素比例算，不按灰度均值算**：用发丝线画在白底上的片子，读起来一直在动，平均像素几乎不变。均值口径会把"指针在走"判成停顿，把"空场"判成停顿。数**真正变了的像素**是无量纲的：192×108 上 0.2% 大约就是一支 2px 指针的面积。

`--ascii` 会逐拍打出墨迹布局的 ASCII 图。**给看不到图的 agent 用的**：它可以直接“读”构图，而不是靠猜。

**极性：上面四个阈值必须先知道“哪一边是画出来的东西”。** “墨”是画上去的材料，“暗”是离画布最远的那个极。白底片的笔迹偏暗，黑底片的笔迹偏亮。旧版把“墨”写死成“低于 245 的像素”，于是黑底片里每一拍都是 100% 墨、每一拍都长得一样——一支每一拍构图都不同的片子会被判成 `layout_repeat`。**假失败比假放行更伤**：它会推着你去修一个根本没坏的画面。

现在 `design_audit.py` 从片子里自己读出画布亮度（每帧中位数的中位数，全局一个值，因为各拍布局要互相比较）：画布 ≥127 走白底一套阈值，<127 走黑底一套，`--polarity light|dark` 可以强制。白底那一套的表达式与标定片时逐字一致，阈值没有放宽。

`--project` 只认 `data.timeline`，而 SKILL.md 明确说 skill 不规定 `data` 的词表。找不到该键时，旧版会**一拍不取**却照旧下结论（打印“最重的一拍 0.00% 墨”），把“没有样本”说成“片子有问题”。现在会退回均匀取样，并在输出里写明用的是哪种取样。

### §1.1 阈值是标定的，不是规定的

上面这支标定片：重量 10.5% 墨 / 1.5% 暗（不达标）、P90/均值 1.54（警告）、停顿 12 个（达标）、布局相似度 0.06（达标）。

也就是说，那支片子的问题**不是**"节奏慢"也不**是**"反复用同一版式"，而是**全片只有一种重量**。这就是为什么"改缓动"救不了它。阈值改的时候要重跑标定片，别凭手感调。

## §2 结构由你定，审计不可跳过

没有强制比较轮：自己选一种宏观结构和一个生成算子（[choreography.md](choreography.md) §2/§3），
只做到 pass 1（骨架），然后**必须**在这一步用工具量一遍——因为“好不好看”在纸面上判断不了：

1. 用 `vs.py rehearse` 渲一段 **4 秒**、0.35 像素、低帧率的草稿。
2. 量它：
   ```bash
   python scripts/design_audit.py 草稿.mp4 --times 1,2.2,3.4 --ascii
   ```
3. 四条判据里任何一条失败（重量单一 / 节奏平线 / 没有可读停顿 / 布局重复），**改结构，不是改缓动**。
4. 通过之后再做 pass 2–5；用过的机制写进 choreography §7。

成本：一段 4 秒草稿约一分钟。**跳过这一步，就是在用最终渲染做设计探索**——而那是最贵、也最容易将就的方式。

## §3 快闪的真实定义

快闪 = **极短的转场 + 被读的停顿**，不是"一直在动"。

| 项 | 数值 | 说明 |
| --- | --- | --- |
| 整帧级转场 | 0.25–0.55s，绝不超过 0.9s | 越快越"快"；两端慢的缓动读起来是慢动作 |
| 停顿 | 0.3–0.7s，且停在**已经到位、正在被看**的画面上 | 停顿期间环境与次级动作仍在动 |
| `hold` 声明 | 把停顿写进 `"hold"` | 停顿窗口渲染器只渲一帧，**加停顿反而更便宜** |
| 每拍子动作 | 2–3 个，不是 5 个 | 30 秒 9 拍 × 5 个子动作 = 40 次状态变化，眼睛来不及读 |

常见误区（本文标定片犯的）：为了"快"，把转场做成 0.8–1.2 秒的软过渡并让它们首尾相连铺满全片。结果是每一拍都在慢慢挪，永远没有新画面落地——**又慢又糊**。

## §4 重量预算：明度对比是最被低估的一条

白底片子必须有**一块暗**，或者**一拍满幅**，否则"白"没有参照，读起来是淡而不是高级。

| 项 | 规则 |
| --- | --- |
| 暗拍 | 全片至少一拍，暗部（<110）占画面 ≥3%；可以是一次反转（暗场白字）、一块黑色面板、或一个占满画幅的深色形体 |
| 密拍 | 或者至少一拍墨量 ≥12%（满幅帧墙、密集格、大字铺满） |
| 反例 | 全片最暗的元素是一根 2px 线；全片最密的一拍 10% 墨 → `no_weight_variety` |
| 出处 | 色彩三档（[taste.md](taste.md) §1.3）管的是色调预算，这条管的是**明度**预算，两者都要 |

## §5 尺度与版式：双峰

- 全片至少一次**巨字**：中文单行占画幅宽度 ≥40%（1920 画幅下 ≥120px 字号），或英文小字层整屏密排。
- 每拍至少换一种构图骨架：极简（一个元素 + 大留白）/ 极繁（满幅密排）/ 特写 / 反转。**相邻两拍不许同一种**。
- `design_audit` 的 `layout_repeat` 只能在**位置**上抓重复；重量与骨架的重复由这条人工过。

## §6 复核顺序（渲染前）

```bash
python scripts/design_audit.py draft.mp4 --project work/mine/project.json --ascii   # 1. 对着 ASCII 逐拍读构图
python scripts/taste_check.py    draft.mp4 --rhythm                                 # 2. 节奏有没有峰值
python scripts/beat_audit.py     work/mine/project.json                             # 3. 交接有没有空档
python scripts/vs.py check       work/mine/project.json                             # 4. 有没有出框/NaN/对比度问题
python scripts/vs.py plan        work/mine/project.json                             # 5. 预算
```

四条设计判据里任何一条失败，**改结构，不要改参数**：缓动、时长、缓动曲线、颜色都改不动"全片一个重量"。
