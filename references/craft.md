# 教程精华：动画设计 · 演示设计 · 版式设计

这份文件是 [choreography.md](choreography.md) 的**手艺层**。那份讲"一支一镜到底的片子怎么编排"，
这份讲"每一帧、每一次运动、每一屏信息怎么做对"。

每一条都是**可检查的**：要么能写成一个闸门（纸面推演的静帧、需要时 `preview` 的单帧、
`verify` 的测量），要么能在
静帧上直接判断。规则不是凭空的，出处见 §5。

---

## §1 动画十二原则 → 逐帧动画检查表

十二原则出自 Thomas & Johnston《The Illusion of Life》，是动画行业最通用的一套语汇
（中文社区称"动画十二原则/十二法则"）。下面把它翻译成**本管线里可检查的形式**。

| # | 原则 | 在这套管线里是什么 | 怎么检查 |
| --- | --- | --- | --- |
| 1 | **挤压与拉伸** | 有质量的东西在加速、落地时形变；用 `scale` 的 x/y 反比 | 落点那一帧有没有形变？形变时 `sx*sy` 是否≈1（体积守恒） |
| 2 | **预备动作** | 大动作前先反向蓄力 | `Anim` 的 `anticipation` 参数是否用在了关键动作上；动作起点有没有"往回一点" |
| 3 | **表演与构图** | 一屏一个焦点，用剪影/明暗/位置把注意力钉住 | 眯眼看静帧：第一个撞进眼里的是不是你想让他看的那个 |
| 4 | **连续动作 / 关键帧** | 本管线天然是"关键帧 + 纯函数插值" | 关键帧之间有没有"中间张"的节奏，还是匀速滑过去 |
| 5 | **跟随与重叠** | 主体停下后附属物继续走（头发、尾巴、粒子、光晕） | 主运动结束时，有没有东西还在动 0.2-0.5 秒 |
| 6 | **慢入慢出** | 缓动 | 每个动作都有 ease？但**时间轴本身保持线性**（choreography §6 第 2 条） |
| 7 | **弧线** | 位移走弧线而不是直线 | `Anim.Actor.to(..., { arc: N })`；直线的横向位移读起来是机械的 |
| 8 | **二次动作** | 不抢主戏的附加动作：粒子、微光、纹理流动 | 二次动作幅度 ≤ 主体动作的 1/3，否则观众读不到主线 |
| 9 | **时间** | 帧数决定重量感 | 同一个动作用 6 帧和用 16 帧是两种情绪；重量大的东西起停更慢 |
| 10 | **夸张** | 把关键特征推到比现实更清楚 | 该大的地方够不够大（对照 §3 的字号跳跃），该快的地方够不够快 |
| 11 | **实体的形体** | 结构、重量、透视与遮挡 | 有重叠/遮挡吗？没有遮挡的画面读不出纵深 |
| 12 | **吸引力** | 观众愿意看下去；不是"可爱"，是清晰 + 有个性 | 关掉动效的静帧是否仍然成立（choreography §8.1） |

**逐帧/定格风味**：把动画量量化到 11-15 Hz（每秒 11-15 个新状态），主体量化、环境不量化
（量化相机会读成卡顿）。

**常见反例**：同时有 3 个以上东西在动（观众读不到主线）；为了"不空"而加的循环动画；
缩放时把形状拉变形（没有体积守恒）；所有动作同一个时长同一个缓动。

## §2 演示设计四原则（PPT）→ 信息设计检查表

**对比 · 重复 · 对齐 · 亲密性**（Robin Williams 提出的四条，中文社区常称"PPT 设计四原则"）。
它们本来是给静态页面定的，但对视频里每一屏同样成立：

| 原则 | 规则 | 违反的样子 |
| --- | --- | --- |
| **对比 Contrast** | 不同的东西就让它明显不同：字号、字重、颜色至少差一档 | 两个本该区分的信息"长得差不多"，观众要靠猜 |
| **重复 Repetition** | 同一套视觉语汇重复出现，观众学一次就懂 | 每一屏的章节标签位置/颜色都在变 |
| **对齐 Alignment** | 每个元素都和另一个元素有视觉连线 | 全部居中然后各自微偏；元素各居其位 |
| **亲密性 Proximity** | 相关的放一起，无关的分开；间距本身就是分组 | 一个间距走天下，观众看不出哪些信息是一组 |

配套的四条信息设计规则：

1. **断言式标题**：标题写**主张**，画面给**证据**。不是"背景介绍"，而是"需求三年涨了三倍"。
2. **一屏一个主张**：一屏里出现两个主张，就说明这一屏要拆（对应 `brief` 的 chapter `intent`）。
3. **数据墨水比**（Tufte）：删掉不承载信息的网格线、阴影、边框、装饰。留下的每个像素要说事。
4. **故事线**：整片按 SCQA（情境-冲突-问题-答案）或"现状 → 变化 → 未来"推进；
   每一章要么回答上一章提出的问题，要么提出下一章要回答的问题。

**图表四条**：先给结论再给数据；比较必须同一基线；不要用面积/体积编码一维数据；
数字要有单位、口径和刻度。

**标重点的正确做法**：先试**改变字号/位置/颜色**，最后才考虑圈框。满屏红框等于没有重点
（中文社区对此有一致的说法："别在 PPT 里加红框标重点"）。

## §3 版式与前端设计 → 构图检查表

### 3.1 构图法（中文版式课的常用语汇）

| 构图 | 什么时候用 | 本管线里的写法 |
| --- | --- | --- |
| 三分 / 黄金比例 | 主体落在线或交点上，而不是正中 | 主体中心放在 1/3 或 2/3 处 |
| 九宫格 | 信息分块、多元素排布 | 3×3 网格，元素落在格线或格内 |
| 三角形 | 三个元素要稳定 | 大-中-小三个重量的三角关系 |
| Z 形 / 对角线 | 有阅读顺序的画面 | 视线从左上到右下（或反之）走一条对角 |
| 留白 | 让主体呼吸 | 主体周围留出不小于主体宽度 1/2 的空 |

### 3.2 前端设计的硬数字

- **网格**：8pt 基准；间距成倍数（8/16/24/32）。
- **字号阶梯**：模块化比例 1.25 / 1.333 / 1.5；最大字与正文的比值 **4-8×**（choreography §4.2）。
- **字体角色**：显示 / 正文 / 数据 三档足够；一屏不要超过两种字族。
- **对比度**：普通文字 ≥ 4.5:1（大字号 ≥ 3:1）；**本管线要求正文 ≥ 8:1**，因为视频编码会进一步压缩。
- **安全区**：竖屏顶部 12%、底部 20% 会被平台界面压住。
- **视觉层次**（从强到弱）：尺寸 > 对比 > 颜色 > 位置 > 运动。
  想让观众先看什么，先动前三个，最后才用运动。

### 3.3 格式塔（分组是怎么被读出来的）

邻近、相似、闭合、连续、**共同命运**（一起动的东西会被读成一组）。
视频里最好用的一条是"共同命运"：想让两个元素被看成一类，就让它们**用同一条曲线同时动**。

### 3.4 反例清单

居中一切；等距平均（没有主次）；装饰性分隔线；一屏三行以上的等宽文字块；
"信息墙"（没有任何层级）；同一屏三种字族；字号全部落在 16-48px 之间。

## §4 把这三套规则写进提示词

**P-A1 用十二原则审一次运动**

```
看这段动画（描述/截图给你）。按动画十二原则逐条过一遍，只列出**真正有问题**的：
预备动作、跟随与重叠、弧线、慢入慢出、挤压拉伸、二次动作幅度、是否有 3 个以上东西同时在动。
每条给出：问题 → 改法 → 改哪个参数。不要给泛泛的表扬。
```

**P-A2 用四原则审一屏**

```
这一屏的信息是：<列出>。请按对比/重复/对齐/亲密性四条检查，再用"断言式标题"重写标题，
最后给一个删减建议（数据墨水比：删掉什么）。输出成"问题 → 改法"的清单。
```

**P-A3 用构图法审版式**

```
这一屏的主体是 X，辅助信息是 Y。请在三分、九宫格、三角形、Z 形里选一种，说明为什么，
给出主体的具体位置（百分比）与留白量，并检查：安全区、字号跳跃倍数、对比度。
```
