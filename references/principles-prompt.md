# 十二原则 prompt（直接粘贴用）

这是一份**提示词**，不是工具：把下面整段粘进你的视频需求里，写场景的 agent 就会按十二
原则办事。原则本身来自动画的经典教学；这里的每一条都翻译成了 `seek(t)` 世界里能执行、
能验收的说法——参数区间与代码写法见 [motion-realism.md](motion-realism.md)，
物理系统的 API 见 [motion-physics.md](motion-physics.md)。

---

## 粘贴用的主 prompt

> 做这支片子时，请把动画十二原则当作硬约束，而不是形容词。静态画面先立住，再让它动。
>
> **1 挤压与拉伸。** 只要有落地、碰撞、加速，就要有形变：落地压扁、起跳拉长；形变必须
> 体积守恒（`scaleX * scaleY ≈ 1`，偏差 ≤ 3%），落点那一帧是形变的峰值，而不是形变
> 的起点。
>
> **2 预备动作。** 每一个主要动作前都要有反向准备：下蹲才起跳，收手才出拳，缩小才放大。
> 预备幅度 3–8% 的行程，时长约主动作的 15–25%，然后才是主体动作。
>
> **3 舞台调度。** 一屏一个焦点：用构图、明暗、虚实、位置把注意力钉在你想要的地方；次要
> 元素不许抢戏（对比度、动速、面积三样都要压过它）。主角在 1/3 或 2/3，不在正中。
>
> **4 连续动作与姿势到姿势。** 先定关键姿势（构图与时间点），再补中间帧（过程与节奏）。
> 讲述型内容用姿势到姿势，质感型内容用连续动作；同一支片子里两种可以混用。
>
> **5 跟随与重叠。** 主体停下后，附属物继续动 0.2–0.5s；不同部分不同时停止（错开
> 0.04–0.18s）；跟随时可以比主体走得更多一点，但永远不能同时到位。
>
> **6 缓入缓出。** 元素走缓动，时间轴保持线性；揭示用快进软着陆，离场才用慢起硬出。
> 全片不许只有一种缓动、一种时长。
>
> **7 弧线运动。** 位移走弧线，不走直线：横向移动时做一条垂直于运动方向、在行程中点达到
> 峰值的偏移。有机的动作走弧线，"科技冷机器"才允许直线。
>
> **8 次要动作。** 主动作之外安排 1–2 个补充情绪或信息的小动作（括号合上、计数跳动、
> 邻格变灰），它们必须从属于主动作——能被删掉而不影响理解，但删掉之后画面会变薄。
>
> **9 时间节奏。** 同一姿势换 timing 就是另一种意思：写清楚哪几秒是刻意停留（写进
> `hold`）、哪几秒连续运动；每拍至少有一个"快—慢—停"的层次差。
>
> **10 夸张。** 该大的够大、该快的够快：把真实动作提炼放大到能一眼读出意图（幅度、
> 速度、形变都可以夸张），但不许用夸张掩盖结构问题。
>
> **11 扎实的造型。** 一切有体积感：透视、比例、投影、接触面（影子、地面、相邻物）都要
> 成立；不允许任何东西像纸片一样飘。
>
> **12 吸引力。** 把魅力做进剪影：关掉动效、缩到 25%、眯起眼看，还认得出主角、读得出
> 主张。吸引力不等于可爱，而是清晰、有个性、有表现力。
>
> 另外：交付前静帧能站住；同一时刻在动的东西 ≤ 3 个；全片只留一个记忆点；三处刻意的不对称。

## 每条原则落到代码上

| 原则 | 可执行写法 | 可测量 |
| --- | --- | --- |
| 挤压与拉伸 | `sx = 1 + k, sy = 1 / (1 + k)`，`k` 由速度或冲击驱动，落点取峰值 | 体积偏差 `abs(sx*sy - 1)` ≤ 0.03 |
| 预备 | `Phys.spring` 反向初值，或 `Anim.withAnticipation(p, 0.06)` | 主位移前存在符号相反的一段 |
| 舞台调度 | 焦点唯一的构图；其余元素降对比、降动速、降面积 | 静帧：墨团数、对称度、重心偏离（`taste_check.py`） |
| 连续 / 姿势到姿势 | 先写在纸面：关键姿势清单 + 时间戳，再补缓动 | 每拍有 money frame 与 intent |
| 跟随与重叠 | `Phys.chain({n, gap: 0.04–0.18, gain: 1.1–1.4})`；附属物晚 0.06–0.15s | 各元素的静止时刻不同（错开 ≥ 0.04s） |
| 缓入缓出 | `ease-out-expo` 用于揭示，`ease-in-quart` 只用于离场 | 速度曲线两端斜率低、中段高 |
| 弧线 | 位移加一条垂向偏移，`sin(pi * p)` 包络 | 路径中点偏离直线的距离 > 行程的 1% |
| 次要动作 | 主体动作触发 1–2 个状态变化（颜色、计数、括号） | 同屏运动元素 2–3 个 |
| 时间节奏 | 时长档位表 + `hold` 窗口 | p90 ≫ mean（有快有慢）；静止比例 40–60% |
| 夸张 | 幅度取真实值的 1.2–1.5 倍，速度峰值提前 | 行程 ≥ 元素自身尺寸 |
| 扎实造型 | 接触阴影、地面线、透视收敛、遮挡关系 | 静帧里物体有落点、不悬空 |
| 吸引力 | 剪影测试：25% 缩略图 + 眯眼测试 + 静帧闸门 | 缩略图仍能读出焦点 |

## 用法

搭在你自己的需求后面即可，例如：

> 用 `$video-studio` 做一支 30 秒的 <主题> 视频。<把上面的主 prompt 整段粘在这里>
> 项目文件里把十二原则落实到数据上：`data.beats[].intent` 写清每拍要观众明白什么，
> 需要刻意静止的秒数写进 `hold`。

写完场景后，先跑 `vs.py scrub <project>` 自己看一遍节奏（这是允许的廉价试演），
再跑一次 `vs.py run <project>` 交付——十二原则的验收就是 `verify` 加上静帧闸门。
